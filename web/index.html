Which setup is yours?


  

    
Laptop & laptop

    
Install the Duet extension on both browsers. It hooks into whatever video is on screen — Netflix, Prime, YouTube, Disney+, Max, Jellyfin, a local file — and keeps both sides in step. Nothing to configure per service.

  


  

    
Laptop & TV — best result

    
Run an HDMI cable from the TV person's laptop to the TV, or cast the browser tab. The extension does the syncing; the TV is just a bigger monitor. Every service works, because the browser is still the player.

  


  

    
Laptop & native TV app

    
A Netflix app on a smart TV can't be driven from outside — no app allows it. Open TV mode there instead and Duet runs a cue console: a shared 3-2-1 countdown, matching timecode, and a plain instruction like skip back 4 seconds when you drift. You press the buttons; Duet tells you exactly when.

  


  

    
Laptop + Fire TV / Toshiba (same Wi-Fi)

    
Create the room on your phone. On a Mac on the same Wi-Fi as the Fire TV: once, Settings → My Fire TV → Developer options → ADB debugging and ADB over network. Then double-click scripts/duet-firetv.command or npm run firetv. Open Netflix on the TV, pause, partner laptop Count us in.

  


  

    
Laptop + Roku (same Wi-Fi)

    
Create the room on your phone at this site. On a Mac on the same Wi-Fi as the Roku, double-click scripts/duet-roku.command or run npm run roku. It finds the TV, logs you in once, and joins your room. Open Netflix on the Roku, pause, then the laptop partner clicks Count us in. Leave that window open.

  


  

    
Nebula Capsule + this Mac

    
On the laptop next to the projector, double-click scripts/duet-capsule.command or run npm run capsule. It logs you in once (password stays in the Mac Keychain), finds the Capsule over ADB, and joins your room if you created it — otherwise it asks for a code. Leave that window open for the movie.

  


  
Duet never copies, relays, or re-streams video. Both of you need your own access to whatever you're watching.
